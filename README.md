# Student Group Assignment System

This system creates balanced team assignments for students across three project domains (Transportation, Health, and Environment) based on survey responses and class enrollment data.

## Overview

The process consists of two main steps:
1. **Initial Assignment** - Create teams based on student survey preferences
2. **Complete Assignment** - Add remaining students who didn't complete the survey

## Prerequisites

### Required Python Packages
```bash
pip install pandas openpyxl PyPDF2
```

### Required Input Files
- `survey_results.csv` - Survey responses from students
- `classlist.pdf` or `seng321_ClassList.xlsx` - Complete class enrollment list
- `group_assignments.xlsx` - Generated by step 1 (input for step 2)

## Step 1: Initial Group Assignment (`group_assignment.py`)

### Purpose
Creates 8 teams distributed across 3 domains based on student survey responses. The script considers:
- Student domain preferences (Transportation, Health, Environment)
- Preferred teammates (attempts to group requested colleagues together)
- Experience balance (courses taken, work experience)

### Domain Distribution
- Transportation: 3 teams
- Health: 3 teams  
- Environment: 2 teams

### Input File Format
`survey_results.csv` must contain columns:
- `name` - Student name
- `needed_colleagues names` - Comma-separated list of preferred teammates
- `Transportation preference`, `Health preference`, `Environment preference` - Numeric ratings
- Course columns: `SENG 275 (Testing)`, `SENG 310 (Human Computer Interaction)`, `CSC 370 (Databases)`, `CSC 375 (Systems Analysis)`
- Experience columns: `UML experience`, `UI experience`, `co-op experience`, `data science experience`, etc.

### How to Run
```bash
python group_assignment.py
```

### Output
- `group_assignments.xlsx` - Excel file with columns:
  - **Team Name** - Team 1 through Team 8
  - **Student Name** - Name from survey
  - **Domain** - Assigned domain (Transportation/Health/Environment)
  - **Score** - Balance score (sum of courses + experience areas)

### Algorithm
1. **Domain Assignment** - Assign students to their highest-rated domain preference
2. **Teammate Preferences** - Move students to be with requested colleagues (within same domain)
3. **Balance** - Distribute students evenly across teams within each domain
4. **Unassigned Students** - Place students without preferences in smallest teams

## Step 2: Add Remaining Students (`add_remaining_students.py`)

### Purpose
Adds students who didn't complete the survey to existing teams, maintaining balanced team sizes.

### Input Files
1. `group_assignments.xlsx` - Output from Step 1
2. `classlist.pdf` (preferred) or `seng321_ClassList.xlsx` (fallback)

### How to Run
```bash
python add_remaining_students.py
```

### Output
- `group_assignments_complete.xlsx` - Complete assignments with columns:
  - **Team Name** - Team 1 through Team 8
  - **Student Name** - Student name from class list
  - **Domain** - Assigned domain
  - **Score** - Balance score (0 for students without survey)

### Algorithm
1. **Load Data** - Read existing assignments and full class list
2. **Identify Gaps** - Find students not yet assigned to teams
3. **Balance Teams** - Add unassigned students to smallest teams (round-robin)
4. **Final Output** - Combine survey-based and new assignments

### Features
- **Name Normalization** - Handles different name formats between survey and class list
- **PDF Support** - Extracts names directly from PDF class list
- **Fallback** - Uses Excel if PDF reading fails
- **Detailed Summary** - Shows team composition, sizes, and total scores

## Complete Workflow

```bash
# Step 1: Create initial assignments from survey
python group_assignment.py

# Step 2: Add remaining students from class list
python add_remaining_students.py
```

## Troubleshooting

### PDF Reading Issues
If PDF extraction fails, the script automatically falls back to reading from `seng321_ClassList.xlsx`. Ensure the Excel file has a "Last First Name" column.

### Name Matching
The scripts normalize names (remove spaces, punctuation, lowercase) to match students between different data sources. If mismatches occur, check for:
- Spelling differences
- Special characters
- Middle names or initials

### Missing Columns
If the survey CSV is missing expected columns, the script will skip those features but continue processing.

## Notes

- Students without survey responses receive a score of 0
- Teammate preferences are only honored if both students prefer the same domain
- The balance score helps ensure teams have similar skill distributions
- Teams within the same domain can have different sizes based on student preferences
